BUSINESS INTELLIGENCE PROJECT

ATM Withdrawal Analysis

An end-to-end data analytics project analysing ATM transaction activity, withdrawal amounts, card usage patterns, and transaction trends.

Project Overview

This project analyses ATM withdrawal transactions to understand transaction volumes, withdrawal amounts, and card usage patterns. The objective is to generate insights that can support ATM operations, cash management, and customer service.

Business Problem

Banks need visibility into ATM usage to optimise cash availability, improve customer experience, and support operational planning. Analysing transaction patterns can help identify periods of high demand and improve ATM management.

Objectives

  • Analyse ATM transaction activity.
  • Measure withdrawal amounts.
  • Compare card usage.
  • Identify monthly transaction trends.
  • Support ATM management decisions.

Tools Used

Excel SQL Power BI DAX

Dataset Overview

The dataset contains ATM transaction information used to analyse withdrawal activity and card usage patterns.

  • Transaction Date
  • Card Type
  • Withdrawal Amount
  • ATM Location
  • Transaction Type

Methodology

The project followed an end-to-end analytics workflow to clean, validate, analyse, and visualise ATM transaction data.

  1. Cleaned and validated transaction data.
  2. Processed the data using SQL.
  3. Created KPIs and calculated measures.
  4. Developed an interactive Power BI dashboard.
  5. Analysed transaction patterns and trends.
  6. Developed recommendations based on the findings.

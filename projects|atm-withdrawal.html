ATM Withdrawal Analysis

Analysing ATM withdrawal activity, transaction values, card networks, locations and withdrawal patterns using SQL and Power BI.

01 • BUSINESS PROBLEM

Understanding ATM Withdrawal Activity

A financial institution processes a large number of ATM transactions every day. Without analysing these transactions, it can be difficult to understand withdrawal behaviour, transaction volumes, withdrawal values, and differences between payment networks such as Mastercard and Visa.

The objective of this project was to analyse ATM withdrawal transactions using SQL and Power BI. SQL was used to clean, validate, and analyse the transaction data, while Power BI was used to identify trends and present the findings through an interactive dashboard.

The analysis provides insight into ATM usage and transaction behaviour, helping the business understand demand and identify opportunities to improve ATM operations and customer service.

08 • BUSINESS INTERPRETATION

Understanding ATM Activity

The dataset contains 1,429,400 ATM withdrawals with a total withdrawal value of R6.05B.

The average withdrawal amount was R522,305.88 based on the transaction measure used in the SQL analysis.

Mastercard represented 54.78% of withdrawal activity, providing a useful comparison point against Visa activity.

Weekday withdrawals totalled 893,391 compared with 536,009 on weekends, indicating higher withdrawal activity during weekdays.

KK Nagar recorded high ATM activity, making it a useful location to monitor when evaluating transaction demand.

09 • RECOMMENDATIONS

Business Recommendations

Monitor ATM transaction volumes

Track withdrawal volumes regularly to understand ATM demand and identify changes in transaction activity.

Use activity patterns for planning

Use weekday, monthly and holiday patterns to support ATM operational and cash planning.

Compare card network activity

Continue monitoring Mastercard and Visa activity to understand changes in customer payment network behaviour.

Monitor high-activity locations

Identify locations with consistently high transaction activity and use the information to support operational planning.

Build recurring transaction reporting

Maintain recurring ATM reporting to monitor transaction volumes, values and operational patterns over time.

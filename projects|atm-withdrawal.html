4. ATM Withdrawal Analysis

Project Overview

This project analyses ATM withdrawal transactions to understand transaction volumes, withdrawal amounts, and card usage patterns to improve ATM operations and customer service.

Business Problem

Banks need visibility into ATM usage to optimise cash availability, improve customer experience, and support operational planning.

Objectives

  • Analyse ATM transaction activity.
  • Measure withdrawal amounts.
  • Compare card usage.
  • Identify monthly transaction trends.
  • Support ATM management decisions.

Tools Used

  • Excel
  • SQL
  • Power BI
  • DAX

Dataset Overview

The dataset contains ATM transaction information including:

  • Transaction Date
  • Card Type
  • Withdrawal Amount
  • ATM Location
  • Transaction Type

Methodology

  • Cleaned and validated transaction data.
  • Processed the data using SQL.
  • Created KPIs and calculated measures.
  • Developed an interactive Power BI dashboard.
  • Analysed transaction patterns and trends.
  • Developed recommendations based on the findings.

Key Insights

  • Total Withdrawals: 1,429,400
  • Total Amount Withdrawn: Over R6 billion
  • Average Withdrawal Amount: R4,234
  • Mastercard transactions accounted for approximately R3.8 billion.
  • Visa transactions accounted for approximately R2.1 billion.
  • Monthly transaction volumes fluctuated throughout the year.

Recommendations

  • Ensure adequate cash availability during peak transaction periods.
  • Monitor high-usage ATMs to reduce downtime.
  • Use transaction trends to improve ATM management and operational planning.

3. Credit Risk Analysis

Project Overview

This project analyses loan application data to evaluate lending risk, applicant characteristics, and default patterns that can support more informed credit decisions.

Business Problem

Financial institutions need to assess lending risk accurately. Poor credit decisions can increase default rates and financial losses.

Objectives

  • Analyse applicant profiles.
  • Measure default rates.
  • Evaluate loan performance.
  • Identify high-risk lending segments.
  • Support better lending decisions.

Tools Used

  • Excel
  • SQL
  • Power BI
  • DAX

Dataset Overview

The dataset contains:

  • Applicant Income
  • Loan Amount
  • Interest Rate
  • Loan Purpose
  • Employment Information
  • Credit History
  • Loan Status

Methodology

  • Cleaned and validated the dataset.
  • Processed and analysed data using SQL.
  • Created KPIs and DAX calculations.
  • Built an interactive Power BI dashboard.
  • Analysed credit risk indicators.
  • Developed recommendations based on the findings.

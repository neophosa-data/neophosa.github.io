BUSINESS INTELLIGENCE PROJECT

Credit Risk Analysis

An end-to-end data analytics project analysing loan applications, applicant characteristics, credit risk indicators, and default patterns.

Project Overview

This project analyses loan application data to evaluate lending risk, applicant characteristics, and default patterns that can support more informed credit decisions.

Business Problem

Financial institutions need to assess lending risk accurately. Poor credit decisions can increase default rates and financial losses. Analysing applicant and loan characteristics can help identify higher-risk segments and support better lending decisions.

Objectives

  • Analyse applicant profiles.
  • Measure default rates.
  • Evaluate loan performance.
  • Identify high-risk lending segments.
  • Support better lending decisions.

Tools Used

Excel SQL Power BI DAX

Dataset Overview

The dataset contains loan application and applicant information used to analyse lending patterns and credit risk.

  • Applicant Income
  • Loan Amount
  • Interest Rate
  • Loan Purpose
  • Employment Information
  • Credit History
  • Loan Status

Methodology

The project followed an end-to-end analytics workflow to prepare, validate, analyse, and visualise the credit risk data.

  1. Cleaned and validated the dataset.
  2. Processed and analysed the data using SQL.
  3. Created KPIs and DAX calculations.
  4. Built an interactive Power BI dashboard.
  5. Analysed credit risk indicators.
  6. Developed recommendations based on the findings.

SQL Analysis

SQL was used to clean, validate, and analyse the underlying credit risk data before developing the Power BI dashboard.

Cleaned Data

The dataset was cleaned and validated to ensure that the information used for credit risk analysis was accurate and consistent.

Power BI Dashboard

An interactive Power BI dashboard was developed to monitor loan applications, lending activity, applicant characteristics, and credit risk indicators.
